# Images

Drop your photos here and reference them in `app/page.tsx`.

## Examples
- `profile.jpg` → use `src="/images/profile.jpg"` in the About section Image tag
- `interest-music.jpg` → update the `image` field in the INTERESTS array in `page.tsx`

Recommended sizes:
- Profile photo: ~700×900px (portrait)
- Interest cards: ~600×400px (landscape)
